# 中文投标模板（程序员客栈 / 猪八戒 / 开源众包 / 微信群）

## 模板 1 — 爬虫/数据采集

```
您好，这个需求我能做。

我的方案：
1. 先确认目标站点有没有公开接口——有接口优先走接口，比解析 HTML 稳定得多；
2. 采集层带重试和限速，避免被限流；
3. 数据做去重和字段归一，输出 CSV/Excel，需要的话直接入库（PostgreSQL/MySQL）；
4. 交付脚本 + README，一条命令跑通，可配定时任务。

我做过的同类项目：一个扫描 6 家交易所、1528 个交易对的采集器，单次约 20 秒完成，
带异常值过滤和并发请求（可作为案例演示）。

两个问题确认下好报价：
1. 大概多少个页面/多少条数据，需要多久更新一次？
2. 结果要文件还是入库？部署在您自己的服务器吗？

如果数据需要登录才能看，请确认是您自己的账号。
```

## 模板 2 — 自动化 / 报表

```
这个可以做成一条命令跑完。

我会按您现在的表格样式来还原格式（表头、颜色、条件高亮、汇总行），
您每天只需要运行一次，或者配成定时任务自动生成，文件名带日期自动归档。

需要您提供：
1. 一份现在用的报表样例（格式比数据更重要）；
2. 原始数据来源：手工导出的文件、数据库、还是某个系统的接口？

如果原始数据现在也是手工导出，这一步也能一起自动化，通常省的时间主要在这里。

报价 XXX 元，工期 1-2 天，交付后 7 天内免费修 bug。
```

## 模板 3 — 机器人 / 告警

```
能做。这类需求的技术难点不是"发消息"，而是两点：
1. 不重复刷屏——同一条告警只发一次（我做内容去重）；
2. 网络失败不丢消息——推送成功才记状态，失败下一轮自动重试。

我的实现方式：定时抓取 → 规则判断 → 渲染消息 → 推 Telegram/钉钉/企业微信，
状态落盘，重启不会重复轰炸。

需要确认：
1. 推送到哪个平台？
2. 多久检查一次，对延迟有要求吗（分钟级还是小时级）？
3. 触发条件具体是什么（新条目 / 价格变动超过 X% / 关键词命中）？

可以先做一个最小版本给您验证效果，满意再做完整版。
```

## 报价话术

- 客户问"多少钱"：先问需求细节，再给区间（"这类通常 1500–3000，看具体几个数据源"），**不要一次报死价**
- 客户压价：`"价格可以按范围缩小来降，比如先做 1 个站点验证，跑通再扩展"`（保单价，减范围）
- 客户要源码：`"源码交付没问题，验收后给；中途只提供可运行的演示"`

## 平台选择

| 平台 | 特点 | 建议 |
|---|---|---|
| 程序员客栈 | 单价比猪八戒高，客户偏技术 | 主攻这个 |
| 猪八戒 | 低价竞争严重 | 只挑 ¥1000+ 的单 |
