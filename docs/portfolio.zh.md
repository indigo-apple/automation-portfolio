## 项目 1 — 多交易所资金费率采集与套利扫描

**问题**：手动对比 6 家交易所的永续合约资金费率，一次要看 1500+ 个合约，人工不可能。

**做法**：并发请求 6 家公开 API → 币种符号归一（`BTC-USDT-SWAP` / `XBTUSDTM` / `BTC_USDT` → `BTC`）→ 按结算周期折算年化 → 过滤流动性差的异常值 → 输出排行榜。

**结果**：覆盖 1,528 个币种，单次扫描约 20 秒，命中 50 个年化 >10% 的机会。

**技术**：Python 3.11、`urllib` + `ThreadPoolExecutor`、无第三方依赖、可直接部署到 Apify。

## 项目 2 — 定时监控 + 阈值告警机器人

**问题**：客户要盯的数据（价格、库存、竞品上新）不可能一直看，漏一次就亏钱。

**做法**：cron 定时抓取 → 阈值判断 → 消息渲染 → Telegram/钉钉推送。带**状态去重**（同样的告警不重复轰炸）和**失败不记状态**（推送失败下一轮自动重试）。

**结果**：已在实际运行的空投监控服务，每天 9:00 自动推送，无人工介入。

**技术**：Python、Telegram Bot API、JSON 状态文件、systemd timer / Hermes cron。

## 项目 3 — Excel 报表自动化

**问题**：财务/运营每天手工从系统导数据、贴进 Excel、调格式，30 分钟起步。

**做法**：读数据 → 清洗 → openpyxl 生成带表头样式、条件高亮（异常标红）、汇总公式、冻结窗格的 xlsx，文件名带时间戳自动归档。

**结果**：30 分钟的工作变成一条命令，产出可直接发老板。

**技术**：openpyxl、pandas（可选）、CSV/SQL 输入。

## 项目 4 — Telegram 交易信誉机器人（生产运行）

**问题**：交易群里的毁约行为没有记录，无法判断对方是否可靠。

**做法**：Go + PostgreSQL 实现用户信誉分、交易状态机（proposed → active → completed/cancelled/disputed）、扣分销毁、管理员人工介入统计。**所有结算在一个事务内完成并保证幂等**（重复点击不会重复扣分）。

**技术**：Go 1.26、pgx、PostgreSQL、Docker、长轮询 + 回调。

---

## 项目 5 — 高并发密钥派生与批量入库

**问题**：需要按 BIP39/BIP44 标准批量生成多链地址并结构化存储，单进程太慢。

**做法**：16 进程并行生成 + PostgreSQL COPY 文本协议批量写入（而非逐行 INSERT），带区间级幂等（重跑安全）。

**结果**：**100,000 组助记词 × 11 条链 = 1,100,000 条记录，62 秒入库**，抽样重派生校验 100% 一致。

**技术**：Python、bip_utils、multiprocessing、psycopg3、PostgreSQL 14。
